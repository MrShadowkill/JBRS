# Архитектура 0.2

Проект остаётся Rust Cargo workspace. Точка входа game/src/main.rs вызывает game::run. Координатор game/src/game.rs сохраняет существующие игровые системы; game/src/world_view.rs управляет GPU-резидентностью, видимостью и интерьерами.

## Модули

- engine_core: Vec3, Team, фиксированный STEP, Vertex/Mesh и построение примитивов/крыш/цилиндров.
- terrain: функция высот, биомы, берег/вода, сетки двух уровней детализации, повторное использование буфера вершин.
- roads: Catmull–Rom дорожные линии, общий tangent на стыках, настил, разметка, мосты и дорожная инфраструктура; дорожный граф и тесты.
- buildings: библиотека шести стилей, оболочки, фасады, footprint, входы, независимые коллизии, мебель, камерные секции, лестница и поддержка площадки казино.
- world: geography.rs задаёт единую географию; lib.rs объединяет данные, строит spatial index коллизий, чанки, навигационную текстуру и аудит; streaming.rs содержит CPU worker и ограниченные очереди с recycling.
- renderer_gl21: SDL2/OpenGL FFI, GLSL 1.20 program, atlas, VBO ownership, texture UI и прежний путь динамических простых моделей. Шейдеры лежат в shaders/world.vert и shaders/world.frag. GL ресурсы создаются/удаляются только на потоке renderer.
- vehicles / vehicle_physics / player: прежние транспорт, аркадная горизонтальная физика 60 Hz и роли. Координатор применяет поддерживающую высоту дороги/местности и потолки.
- police / criminals / weapons / robberies / economy: существующие single-player системы.
- gui / minimap / profiling / save_system: интерфейс, проекция общей карты, измерения frame/RSS/GPU bytes, JSON версии 1.

Многопользовательского сервера нет. networking, audio, missions, character_animation и другие незавершённые подсистемы не представлены пустыми Cargo-заглушками. Полный список ограничений новой карты находится в WORLD_REBUILD.md, исходной игры — в README.md.

Static collision descriptors отделены от render mesh: стены и деревья индексируются ячейками 128 м; окна, карнизы и большая часть мебели не создают по одному физическому телу. Конструктор, joints, Physgun и Toolgun этим изменением не добавлены.

Кэш геометрии создаётся детерминированно в worker. Логические данные районов остаются загружены целиком; дальние VBO выгружаются. Пул CPU массивов ограничен; GPU buffers удаляются через renderer, который владеет GL context. Interiors имеют отдельный lifecycle по текущему зданию.
