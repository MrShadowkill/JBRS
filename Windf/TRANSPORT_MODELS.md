# Стилізований автопарк і транспорт

Восьме авто — **Akari R7**, інтегроване з наданого користувачем
`mazda_rx7_stylised.glb`. Воно припарковане поряд із міським гаражем,
у точці **(440, -72)**: E — викрасти, WASD — керувати, J біля гаража —
обслуговування та фарбування. Білий колір — початковий.

Автор вихідної моделі — **SheldonJ99**, ліцензія **CC BY 4.0**.
[Атрибуція, джерело й опис перетворень](vehicles/assets/ATTRIBUTION.md).
Оригінальний GLB збережено в `vehicles/assets/source/akari-r7.glb`.
Гра використовує вбудовані похідні ресурси й не завантажує GLB під час гри.
Команда `jailbreak-rs --credits` показує атрибуцію також із виконуваного файла.

Решта сім моделей — оригінальна геометрія в близькій стилістиці:
округлені низькополігональні кузови, справжні отвори колісних арок,
широкі кольорові поверхні, обрамлене скління, окремі шини, диски й оптика.
Це різні моделі, а не деформації чи копії меша RX7.

## Сумісність і геометрія

- Індекси 0–6, їхні ціни, характеристики та місця появи збережено.
  Akari додано індексом 7: ціна каталогу 18000, базова максимальна швидкість
  57 м/с, прискорення 17, зчеплення 3.7. У поточній грі її викрадають
  зі стоянки, як і решту машин; магазин створення авто не додавався.
- Збереження з шістьма або сімома авто доповнюються восьмим слотом.
  Попередні кольори, покупки й покращення залишаються; новий слот
  отримує початкові значення. Нові збереження читаються цією версією гри.
- Кузов фарбується окремо від скла, шин, металу, оптики та службових деталей.
  У GLB сріблясті деталі й диски залишені незмінними матеріалами.
- Дві геометрії на авто: ближня й дальня. Поріг відповідає чинному пресету
  графіки; відсікання за полем зору й дальністю збережено.
- Власні моделі: **3720–4000** трикутників зблизька, **1212–1308** здалеку.
  Akari: **5682 / 1080**. Презентаційний floor із GLB не імпортується.
- Меші перевіряються та декодуються один раз, кешуються в CPU-пам'яті.
  VBO створюється один раз на видиму модель, частину й LOD у конкретному
  GL-контексті. Положення, поворот і колір не вимагають повторного upload.
- Рендер використовує OpenGL 2.1 / GLSL 1.20 без нових Cargo-залежностей,
  VAO, PBR або modern-only API. Вершинні кольори містять стримане
  запечене затінення; освітлення часу доби та туман залишаються чинними.
- Фізика лишається чинною аркадною. Ця зміна не додає розбірні кузови,
  фізичні з'єднання чи анімацію обертання коліс.

## Відтворювана підготовка ресурсів

Усі готові `.jbv` ресурси включено до репозиторію, тож для звичайної
збірки Blender або Python не потрібні. Для редагування ресурсів:

```bash
# Оригінальні сім авто; лише стандартна бібліотека Python 3.
python3 tools/build_styled_vehicles.py
# Імпорт GLB та decimate LOD; перевірено з Blender 4.3.2.
blender -b -t 4 --python tools/import_akari.py -- /absolute/path/to/JBRS
```

Формат JBV1: чотирибайтова сигнатура, little-endian u32 кількості
трикутників, далі три вершини на трикутник. Вершина — сім little-endian
f32: XYZ, RGB, прапорець фарбованого матеріалу (0 або 1). Декодер
перевіряє довжину, ліміт геометрії, координати, кольори та узгодженість
матеріалу трикутника; помилки повертаються до запуску рендерера.

## Перевірки

У підготовленому хмарному середовищі:

```bash
. /workspace/.jbrs-tools/env.sh
cd /workspace/JBRS
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --locked --no-fail-fast
cargo build --release --locked
```

Для огляду моделі задайте `JAILBREAK_VEHICLE` від 0 до 7:

```bash
LIBGL_ALWAYS_SOFTWARE=1 MESA_GL_VERSION_OVERRIDE=2.1 \
MESA_GLSL_VERSION_OVERRIDE=120 JAILBREAK_SCENE=vehicle-new \
JAILBREAK_VEHICLE=7 JAILBREAK_FRAMES=60 JAILBREAK_DEBUG=0 \
JAILBREAK_CAPTURE=/tmp/akari.ppm \
xvfb-run -a "$CARGO_TARGET_DIR/release/jailbreak-rs" --smoke-test
```

Сцени `vehicle-paint-new` та `vehicle-lod-new` перевіряють відповідно
червоний кузов і дальній рівень деталізації. Це лише smoke-сцени;
вони не змінюють збереження. `train-new` перевіряє вантажні вагони,
`locomotive-new` — локомотив.

Перевірено вісім авто окремо, перефарбування Akari та дальній LOD,
по 60 кадрів із OpenGL 2.1 / Mesa llvmpipe, без GL-помилок.
Форматування, Clippy та release-збірка проходять.
Повний запуск тестів: **88 успішних, 1 невдалий** (відомий збій нижче).
Тести перевіряють міграцію збережень і збереження нового тюнінгу,
появу й викрадення Akari, її рух, орієнтацію фар, межі й LOD мешів,
кешування та відхилення пошкоджених ресурсів.

Відомий попередній збій:
`world::tests::navigation_exits_cell_block_without_crossing_walls`:
`stuck at -144.30794,-204.92383`. Він відтворювався до зміни моделей.
На Intel HD Ironlake запуску не було; програмний рендерер не підтверджує
FPS на цільовому GPU.

## Потяг

Локомотив **Ironvale D90** та вагони **Ironvale Cargo 25** з попереднього
оновлення збережено: колісні візки, поручні, сходинки, решітки,
зчіпки й дверне обладнання. Відкритий вагон пограбування зберігає
доступну платформу.
