# JBRS Mobile — Android 10 ARM64 (preview)

Тестова Android-версія поточної гри: місто, квартири, транспорт та J-STORE. Ціль — **Android 10 / API 29**, **arm64-v8a**, **OpenGL ES 2.0**, горизонтальний екран. 32-бітний Android не підтримується цим APK.

## Встановлення

Завантажте [JBRS-Android10-arm64.apk](dist/JBRS-Android10-arm64.apk) на телефон і відкрийте файл. Якщо Android запитає, дозвольте встановлення для програми, якою відкрили APK. Після встановлення запускайте **JBRS Mobile**.

Це preview: APK зібраний і підписаний, його структура та GLES2-рендерер перевірені.  Працездатність на конкретному телефоні та FPS поки не підтверджені. Деталі — [VERIFICATION.md](VERIFICATION.md).

## Сенсорне керування

| Елемент | Дія |
|---|---|
| Лівий джойстик | Ходьба; в авто — кермо та газ/гальмо/задній хід |
| Проведення справа | Камера, одночасно з рухом та кнопками |
| RUN | Утримувати для бігу |
| JUMP | Стрибок; повторні натискання допомагають вирватися з наручників |
| USE | Взаємодія; утримування для тривалих дій/збирання |
| CAR / EXIT | Сісти в транспорт або вийти |
| FIRE | Стрільба / удар; також для розбивання вітрин |
| RELOAD | Перезарядження |
| WATER / FOOD у магазині | Купити воду / їжу біля продавця |
| CROUCH / CRAWL | Присісти / повзти |
| CHUTE | Парашут |
| Панель предметів унизу | Вибір предмета чи зброї дотиком |
| MAP / SET / GAR угорі | Карта, графіка й налаштування, майстерня |

Меню та покупки працюють прямими дотиками. Для завдань із кодом є екранні цифри, DEL та OK. У **SET** кнопки **SENS − / SENS +** змінюють швидкість камери зі збереженням налаштування. Для виходу з панелей використовуйте хрестик чи системну кнопку «Назад».

## Збереження та графіка

Збереження розміщене у приватному каталозі застосунку (`files/save.json`), без дозволів на зовнішнє сховище. Воно записується при штатному виході та переході у фон; контакти керування скидаються. Цей lifecycle перевірено на рівні коду; поведінку Android при згортанні/відновленні ще треба перевірити на пристрої. Видалення застосунку видаляє локальне збереження.

Перший запуск використовує LOW, невеликі текстури та вимкнені тіні. Окремий GLES2-рендерер малює світ у буфері шириною до 640 px; HUD і сенсорні елементи малюються у роздільності екрана. Геометрія міста й автомобілів кешується у VBO; фізика та ігрові системи збережені. Настільний OpenGL 2.1 і папка `Windf` залишаються окремими від GLES2.

## Повторна збірка

Потрібні Python **3.12+**, стабільний Rust, CMake, Ninja, Java **17+** з компілятором, Android SDK Platform **34**, Build Tools **35.0.0+**, NDK **27.2.12479018**. Compile SDK 34 використовується для Java-обгортки SDL; мінімальний і цільовий API самого APK — 29.

При встановлених Android SDK Command-line Tools:

```sh
sdkmanager "platforms;android-34" "build-tools;35.0.0" "ndk;27.2.12479018"
```

Налаштуйте `ANDROID_SDK_ROOT` і `ANDROID_NDK_HOME`, потім із кореня репозиторію:

```sh
python3 Android/build_android.py
```

Скрипт завантажує офіційний SDL2 **2.30.11** з перевіркою SHA-256, збирає SDL2 та Rust для ARM64/API 29, компілює Java/DEX, пакує, вирівнює й підписує APK. Gradle не потрібен. Інструменти та їхні кеші не входять до APK. `--help` показує перевизначення каталогів SDK, NDK та збірки. Для native linker flags використовуйте шлях `--build-dir` без пробілів.

За замовчуванням локальний preview-ключ зберігається **поза репозиторієм**, у `~/.cache/jbrs/android-preview.keystore`. Приватний ключ поточної хмарної збірки також не опублікований. Для оновлення встановленого APK потрібен той самий ключ. Власний ключ можна вказати через `--keystore` і `--key-alias`; паролі — через `JBRS_STORE_PASSWORD` та `JBRS_KEY_PASSWORD`. Не додавайте ключі до Git.

Артефакт: `Android/dist/JBRS-Android10-arm64.apk`; SHA-256 — `Android/dist/SHA256SUMS`.

## Перевірка GLES2 на Linux

Потрібні SDL2, GLES2 runtime та Xvfb; на Debian/Ubuntu — пакети `libsdl2-2.0-0 libgles2 xvfb xauth`.

```sh
cargo build --release -p jbrs --bin jbrs --features gles
MESA_GLES_VERSION_OVERRIDE=2.0 LIBGL_ALWAYS_SOFTWARE=1 JBRS_TOUCH=1 JBRS_FRAMES=90 JBRS_QUALITY=0 JBRS_SCENE=jstore-lasers-new xvfb-run -a target/release/jbrs --smoke-test
```

Це тест настільного запуску GLES2 з мобільним інтерфейсом, а не Android-емулятор. `JBRS_TOUCH=1` показує кнопки; реальні жести перевіряються тестами SDL-подій у `touch_game.rs` і модулі `mobile_controls`.
