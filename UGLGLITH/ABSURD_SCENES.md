# Пакет абсурдних сцен: 52 інтерпретації списку

Джерело: [оригінальний список користувача](docs/ABSURD_IDEAS_UK.txt). Реалізація: `game/src/absurd.rs`.

Це 52 процедурні інтерпретації, не обіцянка дослівної реалізації всіх 100 пунктів. Голосових реплік, фотографій, справжнього нескінченного тулуба, рекурсивного рендеру та необмежених спавнерів немає. Персонажі й реквізит зібрані з оригінальної низькополігональної геометрії.

Перша випадкова сцена починається через 3 секунди активної гри. Сцена перемикається кожні 15 секунд або відразу після завершення хвилі глітчу — залежно від того, що станеться раніше. Кожне перемикання скидає 15-секундний таймер; подвійного перемикання в одному кадрі немає. **F6** негайно обирає іншу сцену; **E** взаємодіє з бабусею, диваном, банкоматом, дідом та порталом. Меню призупиняє таймери.

## Межі реалізації

Поки не реалізовані пункти: 12, 14, 16, 17, 18, 20, 22, 23, 25, 27, 28, 29, 30, 33, 34, 35, 38, 39, 40, 41, 42, 43, 46, 47, 49, 50, 54, 55, 56, 60, 61, 62, 63, 65, 66, 67, 69, 70, 73, 79, 81, 83, 87, 88, 91, 92, 93, 98.

Усі нові актори мають окремий фіксований пул із 96 слотів; принтер повторно використовує слоти 32–95. Великі формації — статично підготовлені VBO, а не сотні повноцінних AI. Кожен такий меш має не більше 90 000 вершин. Шейдерні деформації авто та присідання змінюють вигляд; колізії не масштабуються разом із ними.

У головному циклі сцени не створюють `Vec`, `String`, `Box`, нові текстури або VBO. Прототипи, картопляна текстура та формації завантажуються при старті. Звуки модема, квакання, пищалки, мікрохвильовки та джингла синтезовані в коді; сторонні записи Windows не додавалися.

## Відтворення й перевірка

У smoke-режимі можна задати номер сцени:

```sh
cd UGLGLITH
UGLGLITH_SCENE=3 JBRS_SCENE=prison JBRS_FRAMES=120 cargo run --release -- --smoke-test
# Для консолі адміна й табуреток:
UGLGLITH_SCENE=100 UGLGLITH_CAPTURE_DELAY=6.5 JBRS_SCENE=prison JBRS_FRAMES=300 cargo run --release -- --smoke-test
```

Тести перевіряють геометрію кожного прототипу, унікальність номерів, скінченність координат і нуль алокацій при оновленні всіх 52 сцен; окремо — телепортацію NPC, місткість принтера, 8 секунд антигравітації, знак присідання, перетворення пельменя, реальні E-взаємодії та F6. Нові аудіорежими перевіряються на межі піків і незалежність від розміру блока. GL-тест нульових алокацій прогрітого render/UI запускається окремо з дисплеєм.

Фактичні вимірювання на Ironlake й фізичному Windows/Android тут не виконувалися. Результат Mesa/Wine не є гарантією FPS на цільовому ПК.
