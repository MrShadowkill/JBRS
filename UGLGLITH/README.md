# UGLGLITH — JBRS із випадковими глітчами

Окрема копія вихідного коду JBRS з рожево-чорними текстурами, чорними
силуетами персонажів, ривками геометрії та сильно спотвореним звуком.
Ефекти випадково вмикаються на 4–9 секунд і самі зникають.

Запуск на Linux: `./run.sh` або `cargo run --release` з цієї папки.
Потрібні Rust, SDL2 та OpenGL 2.1. Скрипт використовує власне `save.json`
у папці UGLGLITH; `JBRS_SAVE` дозволяє вибрати інший файл.

[Ефекти, таймери й перевірки](GLITCH_UPDATE.md). Основний проєкт розташований
на рівень вище та не змінений цим варіантом. Готові ZIP/APK основної гри
не містять цих ефектів.
