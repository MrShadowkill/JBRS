# Повна карта JBRS → редактор 417

Експорт — статичний знімок світу JBRS 0.7.5: усі 256 чанків (2048 × 2048 м) з LOD0, 101 будівля, 54 інтер’єри разом з квартирами, окремі дахи, каналізація, дороги, колія, водойми, рослинність і декорації. Додано 29 автомобілів початкового автопарку з детальними оригінальними моделями, локомотив і 25 вагонів у початковому стані; вони не анімовані. Стан пограбувань зафіксовано з seed 0; користувацькі збереження не читаються й не змінюються.

## Як відкрити

Розпакуйте `JBRS-full-map-editor.zip`. Відкрийте вкладений `index.html`, натисніть «Открыть JSON» і виберіть `JBRS-full-map.json` (приблизно 106 МіБ). Завантаження потребує часу й пам’яті; перевірено на настільному Chromium.

Повний файл містить близько 1.027 млн вершин, 766 тис. граней, 521 групу та 48 045 блоків. Він трохи перевищує ліміт навіть останнього наданого редактора (1 млн вершин), тому вкладений `index.html` піднімає ліміт до 2 млн. Вихідний редактор користувача збережено як `editor-original.html`. Менші `parts/part-NNN.json` можна відкривати в ньому: кожна частина має менше 100 тис. вершин/граней та 15 МБ, зі збереженням світових координат. Частини не накладаються редактором автоматично — кожна відкривається окремо.

За замовчуванням «Легкий огляд» показує вибірку граней для огляду великої карти; **усі дані залишаються в пам’яті та JSON**. Зніміть галочку для повного відображення (повільніше). Для роботи з будівлею чи авто виберіть групу й натисніть «Наблизити групу»: тоді вона показується повністю, решта приховується. «Сбросить вид» повертає загальний масштаб; зніміть «Лише обрана група», щоб знову бачити весь світ. Максимальна історія undo для великих моделей скорочена до двох дій, щоб не множити споживання пам’яті.

## Групи та примітиви

`Buildings/назва ID` — екстер’єр будівлі; `Interiors/назва ID` — приміщення; `Roofs/назва ID` — дах; `World/x,z` — рельєф, дороги й декорації ділянки; `Cars/назва ID` — ціла машина; `Train/...` — локомотив і кожен вагон. Каналізація виділена в `Prison/Sewer`.

Формат: стандартні `vertices`, `faces`, `faceMaterials`. Блоки розпізнаються за геометрією Mesh::cuboid, мають окремі вісім вершин та шість граней; тому вибираються й редагуються як незалежні об’єкти. Додаткова таблиця `primitives` з `type: "box"`, індексами вершин, діапазоном граней і групою зберігає їхню структуру. Решта геометрії залишається трикутниками/чотирикутниками, без заміни машин кубами. Пари трикутників об’єднуються лише за вихідною діагоналлю 0–2; вихідні поверхні не відкидаються. Редактор під час власного збереження експортує геометрію та групи, але не додаткову таблицю `primitives`; незалежні блоки при цьому залишаються незалежними.

Формат редактора не містить скриптів, фізики, руху трафіку, ігрових подій, колізій і світлових джерел. Передані кольори поверхонь; ефекти шейдерів, емісія та атлас матеріалів гри не відтворюються. Вихідні HTML і документацію формату надав користувач; вони не є інструкціями для зміни ігрової логіки.

## Відтворення експорту

```bash
cargo run --release -p jbrs --example export_editor -- /tmp/jbrs-map-meshes
python3 tools/map-export/pack.py /tmp/jbrs-map-meshes /tmp/jbrs-map-export
python3 tools/map-export/prepare_editor.py path/to/user-index.html /tmp/jbrs-map-export/index.html
```

Rust-експортер використовує ті самі генератори, що гра, без OpenGL і відсікання за камерою. Python-пакувальник використовує лише стандартну бібліотеку. Повний JSON постачається в ZIP через ліміт GitHub 100 МБ на окремий файл. `manifest.json` містить точні кількості, частини й обмеження.
