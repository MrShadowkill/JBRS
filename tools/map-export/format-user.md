# Шаблон города для редактора 417

Откройте city-template.json через «Открыть JSON». В нём два дома (6 и 4 этажа), две машины, дорога, разметка, тротуары и деревья. Это статические модели: машины сами не ездят, фары не освещают сцену.

## Удобное создание: build-city.py

Скрипт собирает кубические детали в поддерживаемый JSON. Запуск: `python build-city.py`. Итог — city-template.json в папке скрипта. Редактируйте вызовы box и циклы перед последней строкой записи файла.

```python
box(
    [10, 0, 20],         # нижний угол X, Y, Z
    [8, 12, 6],         # ширина X, высота Y, глубина Z
    '#e7c49a',          # цвет #RRGGBB
    'Дом В/Стены',      # категория/группа
    opacity=1,         # 1 — непрозрачно, 0 — невидимо
    texture=None       # либо 'brick.png'
)
```

Координаты мировые, единицы условные: удобно считать 1 единицу метром. Y направлена вверх. Размеры положительные. Если текстура отсутствует, виден цвет. Сам PNG/JPG выбирается кнопкой «Загрузить текстуры»; JSON хранит только имя/путь, а не картинку.

### Многоэтажка

```python
for floor in range(8):
    box([20, floor * 3, 10], [10, 0.2, 8], '#aaaaaa', 'Дом В/Перекрытия')
    box([20, floor * 3, 17.7], [10, 3, 0.3], '#e7c49a', 'Дом В/Стены')
box([19.7, 24, 9.7], [10.6, 0.4, 8.6], '#465363', 'Дом В/Крыша')
```

Это пример перекрытий и задней стены; полная сборка четырёх стен с оконными проёмами есть в скрипте. Стена за прозрачным стеклом должна иметь проём, иначе через окно будет видна стена.

### Машина

```python
box([0, 0.4, 0], [4.4, 0.65, 1.9], '#ed805e', 'Машина 3/Кузов')
box([1.1, 1.05, 0.15], [2.1, 0.85, 1.6], '#ed805e', 'Машина 3/Крыша')
box([1.25, 1.2, 0.12], [1.75, 0.5, 0.04], '#a8dbed', 'Машина 3/Стёкла', opacity=0.3)
```

Кузов за стеклом также остаётся видимым: прозрачность не вырезает отверстие автоматически. Колёса в этом шаблоне кубические.

## Группы

`Дом А/Окна`, `Дом А/Стены`, `Машина 1/Кузов`, `Участок/Дорога`.

В текущем редакторе первый сегмент до `/` — категория, последний — выбираемая группа. Используйте два уровня. Это имена групп, а не вложенные системы координат. Выбор группы позволяет двигать, масштабировать, удалять и менять прозрачность всех её деталей. Для выбора целого здания назначьте всем его деталям одинаковый group; выбор всей категории пока не реализован.

## Реальный формат импорта и экспорта

```json
{
  "vertices": [[0,0,0], [2,0,0], [2,3,0], [0,3,0]],
  "faces": [[0,1,2,3]],
  "faceMaterials": [{
    "color": "#a8dbed",
    "group": "Дом А/Окна",
    "opacity": 0.25,
    "transparencyEnabled": true,
    "texture": "glass.png"
  }]
}
```

Это одна плоская грань, не целый куб. vertices — список координат; faces — индексы вершин, начиная с нуля; faceMaterials — по одному материалу на грань в том же порядке. Для второй грани добавьте вторую запись материала. Грани должны содержать хотя бы три корректных индекса. Связанные общими индексами вершины образуют одну выбираемую деталь; независимым деталям нужны собственные вершины.

opacity=0.25 означает прозрачность 75%. transparencyEnabled отвечает за состояние галочки. Чтобы отключить прозрачность, ставьте одновременно opacity=1 и transparencyEnabled=false.

Необязательные поля материала можно пропускать. Используйте стандартный JSON: двойные кавычки, без комментариев и запятой после последнего элемента. Максимум 100 000 вершин, 100 000 граней и 15 МБ на импортируемый файл.

Формат blocks тоже импортируется, но в нём пока поддерживаются только x/y/z (либо position), size, color и texture. Для групп и прозрачности используйте основной формат или генератор box.

Кнопка «Сохранить JSON» экспортирует текущую геометрию и материалы. Текстуры, положение камеры, скрытие групп и история отмены в файл не входят. Вращение объектов, анимации, физика, движение машин, световые источники и игровые действия этим форматом не задаются.
