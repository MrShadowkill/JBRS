JBRS / AUDIO TOOLS

Конвертор звуку → JSON

Відкрий звук, зміни тон і гучність, збережи JSON. Один HTML-файл, працює локально без завантаження звуків на сервер.

WAV, MP3, OGG та інші формати, які підтримує твій браузер. До 60 секунд і 25 МБ.

Зниження тону також сповільнює звук і збільшує його тривалість.

Синусоїди: звук розкладається на короткі блоки з частотами, амплітудами й фазами. Тембр може змінюватись, особливо для шумів і кроків. PCM16 зберігає моноаудіо точніше. Обидва формати містять налаштування тону й гучності.

Завантаж звук, щоб почати.

JSON — дані для функцій синтезу, а не виконуваний код. Його можна відкрити тут повторно. Імпорт цього формату в гру JBRS потребує окремого завантажувача.
