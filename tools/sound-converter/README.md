# Конвертор звуків

Завантаж `index.html` і відкрий у сучасному браузері. Усі стилі й JavaScript містяться всередині; зовнішніх залежностей та мережевих запитів немає. Якщо браузер обмежує локальні файли, запусти в цій папці `python3 -m http.server 8000` і відкрий `http://localhost:8000`.

1. Відкрий WAV, MP3, OGG або інший підтримуваний браузером звук (до 25 МБ / 60 секунд).
2. Зміни тон (−24…+12 півтонів) та гучність або використай пресет. Зміна тону змінює швидкість і тривалість.
3. Прослухай й експортуй JSON або готовий змінений WAV.
4. JSON можна знову імпортувати для прослуховування та редагування.

Обробка переводить звук у моно, 22050 Гц. JSON зберігає звук до застосування ефектів і окремо `effects.semitones` та `effects.gain`. WAV застосовує ці ефекти до семплів.

## Формат `jbrs.sound.v1`

Спільні поля: `schema`, `name`, `sampleRate` (22050), `length` (кількість семплів), `channels` (1), `effects: { semitones, gain }`.

- `encoding: "pcm16-base64"`: поле `data` містить little-endian PCM16 у Base64.
- `encoding: "sine-frames"`: `functions` містить `fftSize: 1024`, `hop: 512`, `window: "hann-periodic"` та `frames`. Кожен блок має `start` (позиція в семплах), `dc`, `nyquist` та максимум 32 елементи `terms: [bin, amplitude, phaseRadians]`. Частота = `bin × sampleRate / fftSize`.

Синтез у блоці, де `i` — локальний індекс семпла:

```text
block(i) = dc + nyquist * (-1)^i
           + sum(amplitude * sin(2*pi*bin*i/1024 + phaseRadians))
window(i) = 0.5 - 0.5*cos(2*pi*i/1024)
```

Блоки починаються з −512, потім 0, 512, …; вони накопичуються з множенням на `window(i)`. Результат ділиться на суму квадратів вікон у кожній позиції. Частоти й фази визначають сигнал до зміни тону. Відтворення має швидкість `2^(semitones/12)` та множник гучності `gain`.

Розклад синусоїдами приблизний: відкидання слабших частот змінює складний тембр, особливо шум і короткі удари. PCM16 точніше зберігає моноаудіо. JSON містить дані, без виконуваного коду або `eval`. Гра JBRS поки не завантажує цей формат.

## Перевірено

У Chromium: імпорт аудіо й JSON, експорт JSON зі збереженням ефектів, експорт WAV і повторне відкриття, відтворення/стоп, мобільна ширина 390 px та відхилення чотирьох некоректних документів. Для тестового сигналу 440 + 880 Гц похибка відновлення синусоїд RMS 0.00536; максимальна PCM16-похибка 0.0000271. Помилок JavaScript у цьому сценарії немає. Фізичний телефон і прослуховування через його динамік не перевірялися.
